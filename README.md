# Plano de Estudos — Schaeffler 2027

Site responsivo para organizar a preparação para a prova de Aprendiz Administrativo da Schaeffler.

## Publicar no GitHub Pages

1. Crie um repositório novo no GitHub.
2. Envie o arquivo `index.html` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch **main**, a pasta **/(root)** e clique em **Save**.
6. Aguarde alguns minutos para o GitHub mostrar o endereço do site.

O site não precisa de instalação nem de comando de compilação.
